braille-quiz

概要

DxLibを用いて制作した、点字をクイズ形式で学習できるアプリケーションです。 ひらがな50音の点字を、母音・子音の規則性を利用しながら学習できます。

制作期間：2025年10月
制作人数：1人

制作目的

点字を「単なる記号」ではなく、
規則性を持ったシステムとして理解できるようにすることを目的に制作しました。

また、社会に役立つソフトウェア制作を経験し、
GUIアプリケーション開発や入力処理の学習も兼ねています。

使用技術

C++

DxLib

Visual Studio


機能

ランダムなひらがな問題の出題

点字入力

正誤判定

ヒント表示

次の問題への切り替え


工夫した点

点字データを0と1の配列で管理をすることで入力された点字との比較と画面上への点字の表示を実装しやすくなった。

GUI上でマウスをクリックすることで点字のON/OFFを切り替え可能にした。

実際に点字を入力することで母音・子音の規則性を理解しやすい設計にした。

黒板風UIにすることで学習であることを意識させた。


苦労した点

点字の座標管理では、6個の点の位置をずれなく表示するべきだと考え、描画座標を調整しながら実装した。

マウス入力判定では、クリック位置からどの点字セルが押されたかを判定する処理の実装に苦労した。

コード量が増加し、読みにくくなったため配列や繰り返しを利用して対応した。
