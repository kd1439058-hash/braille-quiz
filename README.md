
# braille-quiz

## 概要

DxLibを用いて制作した、点字をクイズ形式で学習できるアプリケーションです。 ひらがな50音の点字を、母音・子音の規則性を利用しながら学習できます。

## 制作目的

点字を「単なる記号」ではなく、
規則性を持ったシステムとして理解できるようにすることを目的に制作しました。

また、社会に役立つソフトウェア制作を経験し、
GUIアプリケーション開発や入力処理の学習も兼ねています。

## 使用技術

- C++
- DxLib
- Visual Studio

## 機能

- ランダムなひらがな問題の出題
- 点字入力
- 正誤判定
- ヒント表示
- 次の問題への切り替え

## 工夫した点

- 点字データを0と1の配列で管理
- GUI上で点字のON/OFFを切り替え可能
- 母音・子音の規則性を理解しやすい設計
- 学習しやすい黒板風UI

## 苦労した点

- 点字の座標管理
- マウス入力判定
- 点字パターンと入力の比較処理
- コード量増加への対応
